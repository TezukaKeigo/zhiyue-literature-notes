# 文献阅读与笔记管理系统验收标准

## 1 验收前准备

1. 系统能够正常启动并访问首页。
2. 数据库迁移已经执行，没有缺表错误。
3. 浏览器控制台和服务端日志不存在阻断性错误。
4. 首次验收先注册一个测试账号；密码至少 10 个字符。
5. 建议提前创建“机器学习”和“软件工程”两个标签。

## 2 账号与安全验收

| 编号 | 验收操作 | 预期结果 |
|---|---|---|
| A01 | 首次打开网站并注册个人账号 | 创建成功并自动登录，进入阅读概览 |
| A02 | 退出登录后刷新页面 | 只能看到登录页，不能读取文献数据 |
| A03 | 使用错误密码登录 | 明确提示邮箱或密码不正确，不建立会话 |
| A04 | 使用正确密码登录 | 进入个人文献库，刷新页面后登录状态保持 |
| A05 | 使用相同邮箱再次注册 | 后端返回 409，并提示该邮箱已经注册 |
| A06 | 使用另一个邮箱注册并查看文献库 | 注册成功，文献库为空，看不到第一个账号的数据 |
| A07 | 未登录直接访问任一业务 API | 返回 HTTP 401，不泄露业务数据 |
| A08 | 在左下角设置中修改空间名称并刷新页面 | 左下角显示新名称，刷新和重新登录后仍然保留 |
| A09 | 在左下角设置中切换到“使用说明” | 显示录入、标签、阅读进度、笔记、检索和数据保护说明 |

## 3 核心功能验收

| 编号 | 验收操作 | 预期结果 |
|---|---|---|
| F01 | 录入标题、作者、年份、来源、摘要、状态和标签完整的文献 | 保存成功，文献出现在文献库中，刷新页面后仍然存在 |
| F02 | 打开文献详情 | 正确显示作者、年份、来源、摘要、状态、评分和标签 |
| F03 | 修改文献状态为“阅读中”并保存 | 文献卡片状态改变，阅读概览中的状态统计同步更新 |
| F04 | 按标题或作者输入关键词 | 只显示匹配的文献 |
| F05 | 同时选择状态和标签进行筛选 | 只显示同时满足两个条件的文献 |
| F06 | 分别选择年份和标题排序 | 列表顺序按照所选规则变化 |
| F07 | 在文献详情中新增一条阅读笔记 | 笔记显示在详情中，卡片笔记数量和概览笔记总数同步增加 |
| F08 | 修改笔记内容和页码 | 更新后的内容正确显示，刷新后仍然存在 |
| F09 | 删除笔记 | 笔记消失，相关统计同步减少 |
| F10 | 创建、修改和删除标签 | 标签管理列表、文献筛选项和统计同步更新 |
| F11 | 删除一篇含有笔记和标签的文献 | 文献、关联笔记和标签关系同步删除；标签本身保留 |
| F12 | 删除一个已经关联文献的标签 | 标签和关联关系删除，文献本身仍然存在 |
| F13 | 在录入窗口拖入含文本和元数据的 PDF | 浏览器本地解析文件并辅助填写标题、作者、年份、DOI 或摘要，PDF 原文件不上传 |
| F14 | 拖入非 PDF、超过 20 MB、加密或无法提取文字的文件 | 明确提示原因，仍然可以继续手动录入文献 |

## 4 业务规则与异常验收

| 编号 | 异常操作 | 预期结果 |
|---|---|---|
| E01 | 标题为空时提交文献 | 表单或后端明确提示标题不能为空，数据不保存 |
| E02 | 作者为空时提交文献 | 明确提示作者不能为空，数据不保存 |
| E03 | 输入早于 1800 年或晚于下一年的年份 | 明确提示年份范围非法，数据不保存 |
| E04 | 输入非 HTTP HTTPS 的文献链接 | 明确提示链接无效，数据不保存 |
| E05 | 连续提交标题、作者和年份相同的文献 | 第二次提交提示重复文献，数据库中只有一条记录 |
| E06 | 创建与现有名称相同的标签 | 提示同名标签已存在，不生成重复标签 |
| E07 | 提交空白笔记 | 提示笔记不能为空，笔记数量不变化 |
| E08 | 访问或修改已经删除的记录 | 返回记录不存在提示，不产生服务端错误 |

## 5 统计与数据闭环验收

1. 新增文献后，文献总数增加。
2. 修改阅读状态后，状态分布和完成率即时变化。
3. 新增或删除笔记后，文献卡片笔记数和概览笔记总数同步变化。
4. 修改文献年份后，年份分布同步变化。
5. 给文献增加或移除标签后，标签文献数量同步变化。
6. 页面刷新或重新打开浏览器后，数据保持不变。

## 6 界面与兼容性验收

1. 桌面端侧边栏、统计卡片、文献卡片和详情抽屉无重叠或截断。
2. 手机宽度下侧边栏能够通过菜单按钮打开和关闭，表单可以滚动并提交。
3. 所有新增、编辑和删除操作都有成功或错误反馈。
4. 危险删除操作必须经过确认。
5. 表单控件可以使用键盘聚焦，图标按钮具有可访问名称。

## 7 推荐现场演示流程

1. 注册测试账号，退出后用正确密码重新登录。
2. 创建“机器学习”和“软件工程”两个标签。
3. 录入第一篇文献，状态设为“待读”，关联“机器学习”标签。
4. 使用完全相同的标题、作者和年份再次提交，展示重复文献拦截。
5. 编辑文献，将状态改为“阅读中”，展示概览统计同步变化。
6. 在文献详情新增一条带页码的笔记，再修改该笔记。
7. 录入第二篇文献，使用标题关键词、状态和标签进行组合筛选。
8. 删除第一篇文献，展示文献、笔记和关联数据同步清理。
9. 退出登录并直接访问业务接口，展示身份保护；重新登录后确认剩余数据持久化。

完成上述流程即可覆盖核心功能、正确性与数据闭环、业务规则、异常处理和统计可视化等主要评分项。
